# ADR 0001: 工单状态模型 - 存储状态与计算状态分离

**状态**:已接受

数据库只存 4 个基础状态(unassigned / assigned / processing / completed)+ dueAt;pending_timeout(距 dueAt 不足 2 小时)与 overdue(已过 dueAt)是随 `now` 持续变化的**派生条件**,查询时实时计算、覆盖显示,不落库。

拒绝的方案:6 个状态全落库 + 定时任务扫描更新——状态有延迟、要维护定时任务、任务失败产生脏状态。

读时计算的原则同样适用于时间类告警("我的待办",见 ADR 0004)。全系统的时间判定(超时染色、看板卡、待办)必须收敛到同一判定函数/视图,防止口径漂移。本期无任何后台定时任务。
