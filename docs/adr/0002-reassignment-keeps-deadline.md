# ADR 0002: 改派工单时处理时限不重置

**状态**:已接受

dueAt 锚定工单**录入时刻**:`dueAt = createdAt + duration(complaintLevel)`(特急不设),创建时一次算定,分配/改派永不重算。理由:SLA 是对客户的承诺,从提交起算,客户不关心内部何时分配;未分配的工单也在消耗 SLA,倒逼尽快分配;且无法通过反复改派规避超时责任。

拒绝的方案:改派时从改派时刻重算——对新接手客服更宽松,但会被用来拖延,客户等待时间不可控。

历史注:早期版本曾锚定 assignedAt(首次分配时刻),后修正为 createdAt——修正后"改派不重置"从一条需要主动维护的规则,变成 createdAt 不可变带来的自然结果。

影响:改派可能把已超时/将超时的工单交给新客服——改派界面应显示剩余时间,提醒主管避免甩锅式改派。
