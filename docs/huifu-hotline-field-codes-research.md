# 汇付 400 投诉字段码表核对

核对日期：2026-11-06。独立读取公开官方查询接口源文档及 Webhook 模板；未读取密钥、客户记录，未调用业务 API。查询文档标注最近更新时间为 2026.07.17。[1][2][3]

## 结论

能解析投诉来源：`04` 新浪黑猫；`05` 人行专线；`13` 人行消保；`14` 人行信访。依据是查询返回字段 `complaint_source` 的明确码表。Webhook 使用 `complaintSource`，模板声明支持 `01`—`09`、`11`—`17`，但未重复列出各码中文名称；采用查询码表解释 Webhook 同码值属于跨文档对应，不能据此认定两种接口的所有取值与格式完全一致。[2][3]

查询文档包含 `18` 消费保，Webhook 模板支持范围未列 `18`。两份文档都没有定义来源码 `10`。不要补齐缺号，也不要把未知值归成某个已知来源。[2][3]

## 字段与协议边界

查询接口：`POST https://api.huifu.com/hotline/complaint/ticket/query`，投诉明细位于 `data.complaints[]`；请求参数明确只支持下划线名称。Webhook 事件为 `hotline.complaint`，模板业务字段使用 camelCase；`namespace`、`event_define_no` 保留模板原名。[2][3]

| 含义 | 查询返回 | Webhook 模板 | 证据与限制 |
| --- | --- | --- | --- |
| 投诉来源 | `complaint_source` | `complaintSource` | 查询有完整中文码表；Webhook 有码值范围和 `05` 示例 [2][3] |
| 优先级 | `priority` | `priority` | 查询有完整码表；Webhook 仅示例 `10` [2][3] |
| 问题类型 | `category` | `category` | 查询有完整码表；Webhook 仅示例 `5` [2][3] |
| 投诉事件码 | `event` | `event` | 查询定义五种事件；Webhook 只描述创建、催单、退回触发，示例为 `1` [2][3] |
| 附件列表 | `attachment_list` | `attachmentList` | 两份文档均声明为链接数组的 JSON 字符串，无附件为字符串 `"[]"` [2][3] |

Webhook 文档仅明确列出退款相关三个字段的 Archer 输入别名兼容：`autoRefundFlag` / `auto_refund_flag`、`refundResult` / `refund_result`、`failReason` / `fail_reason`，并说明 Webhook 统一输出 camelCase。不能推定整个 Webhook 输入或输出都允许任意 snake_case/camelCase 互换；也不能把 Archer 内部输入兼容当成查询接口协议。[3]

任务上下文报告实际 Webhook 的 `category` 同时出现数字码和中文 `扣款投诉`；本次未读取原始客户记录复核。两份官方文档均未提供 `扣款投诉` 与某个数字码的对应关系，因此不能将其自动改写成 `1` 或 `5`，也不能按 `category="5"` 反推具体人行来源码。[2][3]

## 事件完整码表

来源：查询请求筛选参数及查询返回 `event`。请求可使用英文逗号分隔多个码值；返回表定义的是单个投诉事件码。Webhook 文档仅明确创建、催单、退回时推送，未承诺回复或完结也触发推送。[2][3]

| 码值 | 名称 | Webhook 文档是否描述该触发场景 |
| --- | --- | --- |
| `1` | 创建 | 是 |
| `2` | 催单 | 是 |
| `3` | 退回 | 是 |
| `4` | 完结 | 否 |
| `6` | 回复 | 否 |

两份文档未定义事件码 `5`。查询支持 `4`、`6` 不代表 Webhook 一定推送这些事件，更不构成本地自动完结工单的业务规则。[2][3]

## 文档与实际报文差异

官方查询和 Webhook 文档均称附件“始终为字符串”，内容为公开 JFILE 下载链接数组的 JSON 编码。[2][3] 任务上下文另报告实际 `attachmentList` 存在数组、字符串两种形态；本次未读取原始报文复核。该差异应作为接入兼容事实单独保留，不能把官方模板写成已经承诺两种类型。

实现建议：已知码显示中文并保留原码；未知码及已有中文文本保留原值。按查询和 Webhook 分别适配字段；附件在验签后兼容数组或 JSON 数组字符串。中文类别不强行编码，来源码 `18` 即使使用查询文档释义，也须保留“Webhook 模板未列出”的证据边界。以上是接入建议，不是官方新增契约。
